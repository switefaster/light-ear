Upgrade everyone in a room to **light-ear v0.2.0** together. This release introduces a shared public room directory and a new room protocol. If you installed the v0.1.0 draft, use its update button or install v0.2.0 from the release assets.

### Discover rooms and stay connected

- Connect once, browse the public rooms your peers know about, and switch rooms while keeping your peer identity and connections.
- A single peer connecting two groups can introduce their members to each other. When a second path proves it can deliver messages, the client shares traffic across the two paths. A peer in another room can help forward traffic within its upload budget.
- Clients prefer healthy peer paths. When a room needs a relay circuit, the client waits for delivery confirmation and a handoff period before releasing it.
- Open **Topology** in the room browser or select the peer count inside a room to inspect the connections your client knows about. Solid lines indicate direct links and dashed lines indicate circuits.

### Room state and updates

- Votes use the room membership recorded when the proposal was created. Playback preparation also uses room membership, so transit helpers have no vote or playback role.
- After a connection interruption, clients request missing chat messages in bounded batches.
- Starting with v0.2.0, the packaged desktop app checks for updates before connecting. A confirmed update requires installation and restart. A client with no known pending update can still use the LAN when the update service is unavailable.

### Downloads

Choose a desktop installer for your operating system. The separate `light-ear-relay-*` executable is for hosting a relay and rendezvous server. The bundled relay uses a predictable identity and is intended for trusted test rooms. [Relay setup](https://github.com/switefaster/light-ear/blob/v0.2.0/README.md#run)

Desktop bundles include the Fraunhofer FDK AAC decoder. Its license notice is included in the release assets. The decoder source is in the archive’s `aac/` directory. [Decoder source](https://static.crates.io/crates/fdk-aac-sys/fdk-aac-sys-0.5.0.crate)
