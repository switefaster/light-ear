light-ear’s first release lets a room chat, build a Bilibili music queue, and listen together. Each listener streams the audio directly from Bilibili. Playback starts once a majority of the room has buffered the track.

### Join a room

Download the desktop installer for your platform from the release assets. On Windows, choose either the setup executable or the MSI. On macOS, open the DMG. On Linux, choose the AppImage or a package for your distribution.

Use the same topic as the people you want to join. On the same LAN, leave mDNS enabled for discovery. Across networks, enter the same reachable relay address. The separate `light-ear-relay-*` download is for people hosting a relay. See the [relay setup instructions](https://github.com/switefaster/light-ear/blob/v0.1.0/README.md#run).

The bundled relay uses a predictable peer identity. Use it for trusted test rooms only.

### Listen together

- Paste a Bilibili BV number or share link and choose a part to append it to the queue.
- Vote to reorder tracks, pause, resume, or skip. You can remove your own queued tracks and seek within the track you requested.
- Reconnecting peers catch up on recent chat and queue state. The peer overview shows which peers have a direct connection and which use the relay.

The desktop bundles include the Fraunhofer FDK AAC decoder for HE-AAC playback. The release assets include its license notice. The [exact decoder source used for this release](https://static.crates.io/crates/fdk-aac-sys/fdk-aac-sys-0.5.0.crate) is in the archive’s `aac/` directory.
