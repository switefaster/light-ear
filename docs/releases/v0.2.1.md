Install **light-ear v0.2.1** on every desktop in your room. Upgrade peers running either earlier draft together so they use the same queue, playback, and room-forwarding rules.

### Room networking

- Browse public rooms, join, and switch rooms while keeping your peer identity and connections. Room membership determines who votes and prepares playback.
- A peer connecting two groups shares room directories and helps discover another path. Two proven forwarding trees can share room traffic, including bounded transit through members of other rooms.
- This build corrects a traffic imbalance seen in the v0.2.0 draft. Ordinary variation in confirmation times could steer most bytes through one gateway. Healthy paths now share traffic using consistent byte accounting. If one path stops confirming delivery, the sender prefers the remaining confirmed path.
- Clients can use a relay circuit when peer routes fail. They verify delivery over the replacement path before releasing the circuit.
- Open **Topology** from the room browser or select the peer count in a room to inspect direct links, relay circuits, forwarding trees, and delivery measurements.

### Queue and playback

- Removing another member’s song requires a majority and a second member’s approval. The queue shows a vote button for those songs.
- A song moves from the upcoming list to **Preparing** when buffering begins. The player shows how many members are ready and how many are needed. One member coordinates each start, and a stalled start gives way to the next queued song after 90 seconds.
- Bilibili playback checks both endpoints for DASH audio before using combined video. It bounds HTTP reads and startup downloads, and lets the room continue receiving messages during media lookups.

### Installation and updates

Choose the desktop installer for your operating system. The packaged app checks for updates before connecting. Once it discovers a required update, use **Install and restart**. Offline LAN use remains available when the update service is unreachable and the installation has no known pending update.

Use the separate `light-ear-relay-*` download to host a relay and rendezvous server. The bundled relay uses a predictable identity and is intended for trusted test rooms. [Relay setup](https://github.com/switefaster/light-ear/blob/v0.2.1/README.md#run)

Desktop bundles include the Fraunhofer FDK AAC decoder. The release assets include its license notice. The decoder source is in the archive's `aac/` directory. [Decoder source](https://static.crates.io/crates/fdk-aac-sys/fdk-aac-sys-0.5.0.crate)
