**Upgrade everyone in the room together.** This release introduces a new room and discovery protocol for sharing local audio. Clients on v0.2.2 and earlier use a separate network.

### Local audio

- Choose **Queue → Add local audio** to share an MP3, FLAC, PCM WAV, or AAC in M4A. After the sender indexes the file, listeners can start with about 12 seconds of decoded audio. The original file path stays on the sender’s device.
- Listeners can pass verified pieces to one another. Seeking in a long MP3 prioritizes the pieces around the new position. Playback can continue after the sender leaves when other listeners have the pieces it needs.
- **Settings → Media transfer** shows traffic by peer and lets you adjust the upload limit. The default is 1 MiB/s.

### Desktop

- The queue has a compact local file control with import progress and cancellation. Settings brings together the playback device, transfer controls, and searchable status log.
- The room header shows your connection status, and a disconnect still raises an alert. **Settings → Leave room** returns to the room directory. Use the mouse wheel over the topology diagram to zoom around the pointer.
- Enter a display name on first launch. The next launch restores the name and relay addresses from your last successful connection.
- The new light-ear app icon was created by ChatGPT.

Choose the desktop installer for your platform, or select **Install and restart** when prompted. Relay hosts can use the separate `light-ear-relay-*` downloads. [Relay setup](https://github.com/switefaster/light-ear/blob/v0.3.0/README.md#run)

Desktop builds include the Fraunhofer FDK AAC decoder. Its license notice ships with the release assets. The decoder source is in the archive’s `aac/` directory. [Decoder source](https://static.crates.io/crates/fdk-aac-sys/fdk-aac-sys-0.5.0.crate)
